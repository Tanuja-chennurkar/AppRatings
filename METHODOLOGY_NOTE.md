# Candidate submission methodology note

The intended source is the official [MoveInSync Google Play listing](https://play.google.com/store/apps/details?id=com.moveinsync.ets), collected with the Python `google-play-scraper` package. The collector records UTC collection time, source URL, country, language and strategy alongside review text, rating, review date, version and developer response fields when the public endpoint returns them. Its bounded recent sample is not exhaustive. Separate targeted 1- and 2-star batches are discovery samples and are not used for overall-rating or prevalence estimates. The collection date range and sample sizes are written into the generated audit and analysis files after a successful run.

Reviews are checked for blank text, rating outside 1–5, invalid dates and duplicate IDs. Invalid rows are exported with exclusion reasons; repeated text is only flagged diagnostically. Categories use transparent, revisable keyword rules, with multiple labels allowed. The included test fixture is synthetic and is only for transformation tests. A manually labeled, stratified validation set has not yet been supplied, so classification precision, recall and F1 are not claimed. No LLM/API classification is used.

Priorities combine displayed issue share, associated rating and explicit disruption/safety phrase indicators in an exploratory configurable heuristic. These components and sample denominators remain visible; the score is not a causal estimate. Product recommendations are hypotheses until verified with internal telemetry. Relevant diagnostics could include booking funnel outcomes, pickup ETA error, GPS update latency, notification delivery, crash-free sessions or support resolution, selected only where the reviews warrant them. No internal MoveInSync architecture, telemetry or root cause is claimed.

The repository is designed to use Python, pandas, NumPy, Plotly, Streamlit, `google-play-scraper`, ReportLab, python-pptx and pytest. In this preparation environment, no Python interpreter was installed, so none of those packages could be executed and no collection, analysis, test run or PDF/PowerPoint generation was completed. Until Python is installed and valid public/imported records are available, results and generated deliverables explicitly remain pending.
